Walking in Grace for Lifelong Impact (WiGLI) – Website Case Study

Project Overview

Walking in Grace for Lifelong Impact (WiGLI) is a nonprofit organization dedicated to improving the lives of vulnerable children, families, and communities through humanitarian and community-focused initiatives.

This project involved contributing to the organization's website by improving its structure, usability, responsiveness, and search engine visibility.
